# unifir: A Unifying API for Calling the 'Unity' '3D' Video Game Engine

Functions for the creation and manipulation of scenes and objects within
the 'Unity' '3D' video game engine (<https://unity.com/>). Specific
focuses include the creation and import of terrain data and
'GameObjects' as well as scene management.
